# Backend Migration Status — Express.js + TypeScript

## Branch
`main` (standalone backend-ts directory)

## Architecture

- **Runtime**: Express.js + TypeScript (tsx watch mode)
- **ORM**: Prisma 6 with SQLite (dev) / PostgreSQL (prod)
- **Auth**: Token-based (UUID key stored in `tokens` table)
- **Port**: 4000

## Directory Layout

```
src/
├── index.ts              # Entry point
├── app.ts                # Express app config + route mounting (23 routes)
├── config/
│   └── database.ts       # Prisma client singleton
├── middleware/
│   ├── auth.ts           # authMiddleware + optionalAuth (accepts Bearer/Token)
│   └── upload.ts         # File upload middleware
└── routes/               # 23 route files, 24+ mounted endpoints
    ├── auth.ts           # login, register, logout, me, update-profile, team, dashboard
    ├── tickets.ts        # CRUD tickets + comments
    ├── tasks.ts          # CRUD assigned tasks
    ├── goals.ts          # CRUD daily goals
    ├── reports.ts        # CRUD daily reports
    ├── submissions.ts    # CRUD submissions
    ├── chat.ts           # Chat rooms + messages
    ├── notifications.ts  # Alerts (GET list, POST create, POST :id/mark_read)
    ├── files.ts          # File upload/download
    ├── working-hours.ts  # Check-in/check-out
    ├── structure.ts      # Structure boards (collaborative canvas)
    ├── boards.ts         # Flow-diagram boards (Node/Edge canvas)
    ├── groups.ts         # Group management
    ├── services.ts       # Registered services
    ├── telegram.ts       # Telegram integration
    ├── admin.ts          # Admin dashboard/settings/logs (developer-only)
    ├── checklist.ts      # Personal checklist
    ├── event-templates.ts# Calendar event templates
    ├── exercises.ts      # Daily exercises
    ├── notes.ts          # Permanent notes (field: title + content)
    ├── calendar.ts       # Calendar events + comments
    ├── users.ts          # User list
    └── google-sheets.ts  # Google Sheets sync config
```
